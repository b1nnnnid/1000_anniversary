# 우리의 1000일 💗

남자친구와의 1000일을 기념하는 파스텔 픽셀아트 웹앱.
온보딩 → 캐릭터가 **분기 있는 길(스테이지)**을 따라 걸으며 추억을 모으고,
화면 구석 아이콘으로 미니게임(퀴즈·소원권 룰렛)에 들어갑니다. 모바일 우선 디자인.

## 기술 스택
- **Next.js 14** (App Router) + **TypeScript**
- **React + Canvas** : 세로 스크롤 추억탐방 맵 (캐릭터 이동·카메라 추적)
- **Prisma + SQLite** : 진행상황·소원권 저장
- **갈무리(Galmuri)** 픽셀 폰트 / Tailwind

## 처음 실행하기
```bash
# (이전에 설치가 꼬였다면 먼저) node_modules, package-lock.json 삭제
npm install
npx prisma db push      # SQLite DB 생성
npm run dev             # http://localhost:3000
```
> DB 없이도 앱은 켜져요(진행상황 저장만 안 됨).

## 화면 구성
- `/`      온보딩(시작) 화면 → "여행 시작하기"
- `/map`   메인: 세로 스테이지 트레일 추억탐방 + 구석 게임 아이콘
- `/games/quiz`      커플 퀴즈 → 통과하면 룰렛 기회 🎟 획득 (만점이면 2장)
- `/games/roulette`  소원권 룰렛 (기회 🎟 1장 소모) + 쿠폰 이미지 저장

## 티켓 조각(🧩) → 티켓(🎟) 시스템
보상은 **티켓 조각**으로 주어지고, **5조각이 모이면 자동으로 티켓 1장**이 됩니다.
- 스테이지 아케이드 미션 성공: 🧩 +2 (스테이지당 1회)
- 숨은 하트 조각 줍기: 개당 🧩 +1 (총 8개)
- 길가 고양이 첫 만남: 🧩 +2
- 커플 퀴즈 통과: 🧩 +1 (만점이면 더)
티켓 🎟 1장으로 소원권 룰렛을 1회 돌립니다.

## 스테이지 아케이드 미션 (7종, 스테이지마다 다름)
2지선다 퀴즈 · 숨은 하트 찾기 · 사진 조각 퍼즐 · 🍪떨어지는 쿠키 받기 ·
🎯타이밍 탭 · 💗하트 캐치 · 🎵순서 기억(사이먼). 문제/종류는 `lib/gameData.ts`에서 수정.

## 탐방 후 "우리의 공간" (🌸 상봉 후 해금)
- ⏳ **함께한 시간**: 시작일부터 초 단위 실시간 카운터 (시작일은 `lib/config.ts`의 `START_DATE`)
- 📷 **추억 앨범**: 모은 추억 사진 갤러리
- 🎟 **소원권 보관함**: 룰렛에서 뽑은 소원권 목록 + 사용 체크
- 💬 **카톡 대화 분석**: 카카오톡 내보내기 .txt 업로드 → 메시지 수·먼저 연락·많이 쓴 말·새벽 톡 등 (전부 브라우저 안에서만 처리, 외부 전송 없음)

## 룰렛 기회(티켓) 구조
소원권 룰렛은 그냥 돌릴 수 없고, **커플 퀴즈를 통과해 기회(🎟)를 얻어야** 돌릴 수 있어요.
기회는 DB(`Progress.tickets`)에 저장되고, DB가 없으면 브라우저(localStorage)에 임시 저장됩니다.
> ⚠ 스키마가 바뀌었으니 pull 후 한 번 `npx prisma db push` 를 실행하세요. (fragments 컬럼 추가)

## 내용 바꾸기
- **추억 스테이지**: `lib/gameData.ts`의 `STAGES` 배열 (순서 order, 위치 col/row, 사진, 글).
  같은 `order`에 노드를 2개 두면 길이 두 갈래로 갈라졌다 합쳐집니다(분기).
- **사진**: `public/photos/`에 넣고 `photo` 경로 맞추기.
- **퀴즈 / 소원권**: 같은 파일의 `QUIZ_SETS`(테마별 세트, 세트당 최초 통과 시 1회 티켓) / `WISHES`.
- **도착지**: `GOAL`. 모든 추억을 모으면 열리고 폭죽이 터집니다.

## 진행 규칙 (스토리)
- 스테이지는 **위에서부터 순서대로** 열려요. 이전 추억을 안 열면 다음은 🔒 잠김(회색).
- 길고양이 🐱가 가끔 ❗ 띄우고 다가와 말을 걸어요 (스토리 대화, 첫 만남엔 🎟 선물).
- 추억을 전부 모으고 도착지에 가면 **커플 상봉 연출** → 이후 세상이 핑크빛(벚꽃·꽃잎)으로 변하고
  여자친구가 뒤따라오며 **둘이 함께** 돌아다녀요.
- 우측 상단 🏠 "처음으로"는 확인 팝업 후 **모든 진행 데이터를 초기화**하고 온보딩으로 돌아가요.
